# STEPPESHIELD

Веб-карта, которая связывает спутниковые данные о пожарах с местами обитания
редких видов Казахстана, показывает, какие виды под угрозой прямо сейчас,
и присылает тревоги в Telegram.

Сайт: https://dkktqqyvpx-ops.github.io/STEPPESHIELD/

## Что нового

- **Отсев газовых факелов.** Сайт берёт пожары за 10 дней и ищет точки, которые
  горят на одном месте (в радиусе 750 м) 4 и больше разных дней. Степной пал за
  сутки уходит дальше, а факел светится неделями. Такие точки показаны серым,
  по умолчанию не создают тревог, и это можно выключить галочкой.
- **Telegram-бот.** Каждые 3 часа GitHub Actions берёт свежие пожары, считает
  тревоги и отправляет новые (риск от 60) в канал. Одна и та же тревога
  второй раз не приходит.
- **Карта без ключа.** Тот же запуск сохраняет пожары в `data/fires.json`,
  поэтому любой посетитель видит живые данные. Ключ FIRMS хранится в секретах
  GitHub и в коде не виден. Пока данных нет, сайт показывает демо.
- **Кнопки в сообщении бота:** «Открыть на карте» сразу открывает нужную
  тревогу, «Маршрут к огню» строит путь в Google Maps.

## Как включить бота (15 минут, один раз)

### 1. Создать бота и канал

1. В Telegram откройте **@BotFather**, отправьте `/newbot`, придумайте имя
   и username (например `steppeshield_alert_bot`). Скопируйте токен вида
   `1234567890:AA...`.
2. Создайте **публичный канал**, например `@steppeshield_alerts`.
3. В настройках канала: Администраторы → Добавить администратора → найдите
   своего бота → разрешите «Публикация сообщений».

### 2. Добавить секреты в репозиторий

GitHub → репозиторий STEPPESHIELD → **Settings → Secrets and variables →
Actions → New repository secret**. Нужны три секрета:

| Имя            | Значение                                  |
|----------------|-------------------------------------------|
| `FIRMS_KEY`    | ключ NASA FIRMS                           |
| `TG_BOT_TOKEN` | токен от @BotFather                       |
| `TG_CHAT_ID`   | username канала, например `@steppeshield_alerts` |

### 3. Залить файлы и запустить

1. Загрузите в репозиторий все файлы из архива, включая скрытую папку
   `.github/workflows/`. Проще всего через GitHub Desktop или
   `git add . && git commit -m "бот и отсев факелов" && git push`.
   Через веб-интерфейс папку `.github` можно создать вручную: Add file →
   Create new file → имя `.github/workflows/update.yml`, вставить содержимое.
2. Вкладка **Actions** → «Обновить пожары и отправить тревоги» →
   **Run workflow**. Через минуту в канале появится сообщение, а в
   репозитории папка `data/`.
3. Дальше запуск идёт сам каждые 3 часа.

Если вкладка Actions попросит подтверждения («I understand my workflows…»),
нажмите его. Если пуш из Actions не проходит: Settings → Actions → General →
Workflow permissions → **Read and write permissions**.

### На защите

Покажите QR на канал, попросите жюри подписаться, затем нажмите
**Run workflow** с галочкой «Отправить проверочное сообщение». Через минуту
у всех на телефонах придёт самая опасная тревога на сегодня.

## Как запустить локально

Откройте `index.html` в браузере или через Live Server в VS Code. Без
интернета или без данных включаются демо-данные (в них 4 факела, один
рядом с гнездовьями, чтобы было видно, как работает отсев).

## Файлы

- `index.html` — разметка: главная страница и карта
- `styles.css` — оформление
- `core.js` — общие расчёты: разбор FIRMS, поиск факелов, тревоги (сайт и бот)
- `app.js` — сайт: загрузка данных, карта, список тревог
- `scripts/update.mjs` — скрипт бота: данные, `data/*.json`, Telegram
- `.github/workflows/update.yml` — расписание запуска скрипта
- `data/` — появляется после первого запуска, обновляется ботом

## Как считается риск

риск = вес категории МСОП (CR 5, EN 4, VU 3, NT 2) × (1 − расстояние / радиус) × 20

Получается число от 0 до 100. Чем реже вид и чем ближе огонь, тем выше.

## Ограничения отсева факелов

- Новый факел распознаётся только после 4 дней наблюдений.
- Облачность скрывает часть пролётов спутника.
- Долго горящая свалка или торфяник тоже попадут в «постоянные источники».
  Поэтому такие точки не удаляются, а помечаются, и их можно вернуть в тревоги.
